# v1.19.3 - Minor

### Features
- Added the !xph party command.
- Added Hotspot, Treasure, and Trophy party creation buttons.
- Added an all chat share button in the hotspot message.
- Made the nearby player hiding trigger only while fishing (configurable in other settings)
- Added configurable global player armor hiding, the nearby player one takes priority.
- Added Halloween decorations for pf, see them October 30th - Nov 1st! (Seasonal effects toggle in Other settings)
- Added DNS troubleshooting advice when hovering over the websocket connection warning.
- Added a Wither Impact requirement to Party Finder.

### Changes
- Added the session timer to the !sch party command.
- Party Finder now supports exact overflow XP requirements after Fishing 50.
- Removed blizzard in a bottle timers
- Improved the background contrast of unhovered island options when creating a party.
- Full parties now stay in Party Finder and are ordered by newest non-full first.
- Moved party finder requirements below the island and liquid cards for readability.
- Moved Party Finder report/delete icons next to the leader's name and added tooltips.
- Party finder filters now stay active when the panel is closed.

### Fixes
- Fixed hotspot messages now show the correct color.
- Fixed Can Join filtering.
- Fixed Party Finder cards overlapping or leaving gaps after updates and improved layout performance.
- Fixed Slugfish and flare timers freezing when NoammAddons' Time Changer is enabled.
- Fixed Alpha server changes overwriting saved utility data.
- Extended the SkyOcean text width fix to emoji suggestions.
  - Also fixed inconsistency on the sizes of text with the patch.
- Switched emojis to vanilla inline sprites to not conflict with hypixel's texture pack.

### Backend
- Bloodshot requirements now checks through the back-end.
